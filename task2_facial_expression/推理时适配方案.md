# 无标签推理时微调

用户于 2026-10-18 明确提出可以进行推理侧微调。在 Dima 训练完成后执行，验证集只在适配完成后用于比较配置；测试标签不可用，也不进入优化。

## 论文与改造

- [MEMO，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/hash/fc28053a08f59fccb48b11f2e31e81c7-Abstract-Conference.html)，[作者代码](https://github.com/zhangmarvin/memo)：最小化同一图像不同增强视图的平均预测分布的熵。这里使用原图、翻转、小幅中心裁剪、轻微亮度变化四种视图；平均只跨同图视图，不跨不同图片。
- [EATA，ICML 2022](https://proceedings.mlr.press/v162/niu22a.html)，[作者代码](https://github.com/mr-eggplant/EATA)：借鉴低熵可靠样本筛选，排除高不确定性样本的适配梯度。这里没有实现原论文的跨批冗余过滤和 Fisher 正则，因此称为 EATA 启发的熵最小化，而不是完整 EATA。
- 原 MEMO 是逐图适配全部参数；这里为逐批适配末端 LayerNorm，只更新最后四个 ViT 块和最终 LayerNorm 的 13,824 个参数，每批最多两步 Adam。每批后恢复参数与优化器状态，不连续累积更新。

## 固定对照

1. 可靠样本熵最小化，熵阈值 0.4×log(6)，学习率 1e-3。
2. MEMO-LN，学习率 1e-4。
3. MEMO-LN，学习率 1e-3。

均 batch=16、两步、seed=42。在不使用标签的情况下适配，再按已有原图/翻转设置输出预测。只有固定验证准确率提高至少 0.25 个百分点才采用；否则保留原始推理。

验证图原文件排列与类别相关，因此先用 seed=42 无标签随机排列再组批，避免标签排序给批量适配带来虚假优势。测试端执行相同规则，预测恢复原 ID 顺序。批内适配依赖一起出现的图像，必须连同 batch、排序种子和重置策略一起复现。

训练侧 smoke 检查：确实发生参数更新、分类头不变、每批与整轮结束后参数精确复位、重复推理类别一致且概率差在 1e-5 容差内（GPU 反向运算不要求逐位相等）。结果保存在 dima_tta_verification.json。最终比较写入 dima_tta_results.json，是否采用以 adopted 为准。

命令：`python -u -X utf8 fer_project/tta_dima.py`。若采用，`infer_dima_finetuned.py` 自动调用相同适配过程复现最终预测；不把临时适配参数当作一个固定 checkpoint 保存。
