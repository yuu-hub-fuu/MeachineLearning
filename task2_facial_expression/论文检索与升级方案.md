# 六类表情识别：论文检索与预训练升级方案

检索日期：2026-10-18。目标是在既定单种子、单次留出验证设置下提升比赛表现。用户提供的信息是本比赛榜单已有约 0.90；本文不把其他数据集的 90% 当成本题已达到的分数。

## 核心判断

已完成的 EfficientNet-B0 基线在 4,256 张分组留出验证图像上，翻转 TTA 准确率为 **70.91%**，Macro-F1 为 **68.63%**。主要混淆包括 Sad→Neutral 152 张、Fear→Sad 110 张。仅在同一骨干上叠加小模块，尚无证据能弥补到 90% 的差距。下一阶段优先改变**预训练特征来源和特征适配方法**，原有基线保留作比较。

## 优先阅读并使用的论文

以下 CVPR、ICCV、AAAI、NeurIPS 论文来自主会；ICLR/SAM 与 ICPR/RMN 单列为补充，不冒充本次要求的 CCF A 主会方案。

| 论文 | 发表与一手来源 | 与本题直接相关的方法 | 本项目采用程度 |
|---|---|---|---|
| QCS: Feature Refining from Quadruplet Cross Similarity for Facial Expression Recognition | AAAI 2025，[论文](https://ojs.aaai.org/index.php/AAAI/article/view/32814)，[全文](https://arxiv.org/html/2411.01988v1)，[作者代码](https://github.com/birdwcp/QCS) | 用两类各两个样本的局部交叉相似性，压低冗余、加强可区分的局部特征；训练知识转移到单图推理分支 | **首选强表情预训练模型**。下载作者 FERPlus 权重，保留单图分支；先测原始头，再适配六类。不是从头完整复现四分支训练 |
| Navigating Label Ambiguity for Facial Expression Recognition in the Wild（NLA） | AAAI 2025，[论文](https://ojs.aaai.org/index.php/AAAI/article/view/32476)，[作者代码](https://github.com/jungyu0413/NLA) | 联合真实标签概率和最大竞争类别概率，建模样本模糊性；结合翻转一致性，避免一概删掉困难样本 | **首选第二条预训练路线**。作者 RAF-DB ResNet18 权重用于跨数据源比较；噪声策略另作适配消融 |
| Self-Supervised Facial Representation Learning with Facial Region Awareness（FRA） | CVPR 2024，[论文](https://openaccess.thecvf.com/content/CVPR2024/html/Gao_Self-Supervised_Facial_Representation_Learning_with_Facial_Region_Awareness_CVPR_2024_paper.html)，[作者代码](https://github.com/zaczgao/Facial_Region_Awareness) | 全局与区域表示的一致性；区域热图和聚类，使特征关注局部面部区域 | 解释为什么局部特征值得做；目前未核实可直接下载的作者预训练权重，不作为今晚必达依赖 |
| General Facial Representation Learning in a Visual-Linguistic Manner（FaRL） | CVPR 2022，[论文](https://arxiv.org/abs/2112.03109)，[作者代码及权重](https://github.com/FacePerceiver/FaRL) | 面部图文对比与掩码图像学习，提供通用面部表示 | 第二梯队。已核实作者权重发布，但未下载；需要另训练表情分类头，不等于即用型表情分类器 |
| Multimodal Prompt Alignment for Facial Expression Recognition（MPA-FER） | ICCV 2025，[全文](https://arxiv.org/html/2506.21017v1)，[会议论文](https://openaccess.thecvf.com/content/ICCV2025/papers/Ma_Multimodal_Prompt_Alignment_for_Facial_Expression_Recognition_ICCV_2025_paper.pdf) | 冻结 CLIP，联合视觉/文本提示、语义描述和原型对齐；关注局部与全局的关系 | 有价值的后备研究方向。目前未核实官方开源模型，不用未经验证的第三方复现作为主线 |
| Supervised Contrastive Learning（SupCon） | NeurIPS 2020，[论文](https://papers.nips.cc/paper/2020/file/d89a66c7c80a29b1bdbab0f2a1a94af8-Paper.pdf)，[作者代码](https://github.com/HobbitLong/SupContrast) | 同类样本与不同视图拉近、异类拉开，直接优化特征空间 | 用于小型特征适配器的独立对照；低权重加入，避免错误标签把错误正样本强行拉近 |

补充方法：

- **SAM，ICLR 2021**：[论文与说明](https://research.google/pubs/sharpness-aware-minimization-for-efficiently-improving-generalization/)、[作者代码](https://github.com/google-research/sam)。在参数邻域内优化损失，提高平坦性；需要两次前后向。QCS 作者训练已采用 SAM。先评价预训练模型与廉价特征适配，再决定是否值得支付端到端 SAM 的计算成本。
- **Residual Masking Network，ICPR 2020**：[作者仓库](https://github.com/phamquiluan/ResidualMaskingNetwork)、[作者权重](https://huggingface.co/phamquiluan/ResidualMaskingNetwork)。残差空间掩码增强局部表征，提供 FER2013 训练模型。它是实用的预训练参照，**不属于上表的 CCF A 主会方法**。

## 不能混淆的分数与数据来源

QCS 作者仓库报告 FERPlus 91.41%，使用额外 AffectNet 训练时 91.85%；MPA-FER 报告 FERPlus 上 ViT-B/16 为 91.15%、ViT-L/14 为 91.81%。这些来自各自论文协议，类别、标签质量和数据划分均与本题不同，不能用来承诺本比赛分数。QCS 预印本的部分消融还使用多次运行报告最大值，本项目始终仅 seed=42。

本题总计 35,340 张，与 FER2013 去除 Disgust 后的数量相符，各类训练计数也符合按类约 80% 重划分的规律；这是**来源线索，不是已完成图像核验的结论**。FERPlus 与 FER2013 共用原始图像，因此 **QCS/FERPlus 和 RMN/FER2013 两种权重都可能见过本地验证或竞赛测试的源图像**。使用这些权重时必须标注“外部预训练、潜在源图像重叠”，本地高分不能宣称独立泛化结果。NLA/RAF-DB 路线单独报告。没有下载外部隐藏标签，也不通过匹配图像回填测试答案。

## 具体实验顺序

所有方案保持相同 seed=42、相同 24,019/4,256 分组留出划分；不做 K 折。原始测试集没有标签，不能承担模型选择工作。

1. **预训练起点。** 严格加载作者 checkpoint，核对原始标签顺序、输入归一化和模型输出。分别评价原图与水平翻转平均，不先随机重置已有表情分类头。
2. **冻结特征。** 提取原图及翻转的分类头前特征，缓存到 D 盘。对照原始分类头、六类线性头和小型残差适配器。适配器从恒等映射开始，保留预训练决策边界，再逐步学习本题标签体系。
3. **针对特征的训练。** 对适配器做 CE 与 CE+SupCon 对照；后者同时检查翻转视图的一致性。用训练样本的预测可靠度限制噪声样本在对比项中的影响，保留其分类监督，不自动改标签。明确这是借鉴论文思想的适配，不称为完整 NLA/QCS 复现。
4. **有限端到端微调。** 仅在冻结特征结果说明值得继续时，考虑先分类头、后末端块的分层学习率；先检查普通优化，再考虑 SAM。8GB 显存和剩余时间决定是否运行，不预先声称已完成。
5. **推理增强与融合。** 原图→翻转→小幅裁剪/多尺度，逐项评价；采用条件为固定验证准确率至少提升 0.25 个百分点。不同预训练来源的模型按误差互补性比较，先试等权双模型，不扫描大量权重。kNN 特征原型只用训练侧标签构库。
6. **全量适配与生成。** 验证确定配置和轮数后，用全部有标签训练图重训适配器/模型，生成与原模板 ID 顺序一致的 CSV。没有实测增益的增强不纳入最终预测。不会自动使用 Kaggle 每日 5 次提交额度。

## 错误数据处理

已经发现 39 组同像素但训练标签不一致的图像；这类冲突与“模型预测不一致”不同。保留原始标签并输出复查记录。对 Fear/Sad、Sad/Neutral 重点检查混淆矩阵、类别召回、特征最近邻和多模型分歧。只有高置信度预测错误不够证明错标，也不能把困难样本全部删除。

## 实现与来源记录

- 所有模型、下载临时文件、特征缓存及训练 checkpoint 在 `D:\FER2026task2`。C 盘只保存代码、论文说明与轻量结果。
- 预训练来源、文件长度和 SHA256 写入 manifest。作者依赖代码保留 MIT LICENSE 和来源清单。
- NLA 作者使用均值 `[0.577,0.4494,0.4001]`、标准差 `[0.2628,0.2395,0.2383]`，不能套用 ImageNet 归一化。
- NLA 代码的所谓 JSD 与常规定义不同，协方差调度常量也与论文描述存在差别；若改用标准概率 JSD，需明确写作“改造版一致性损失”。
- 迁移 QCS 单图分支时，只允许排除作者训练专用的交叉分支参数；其余缺失、形状不匹配一律报错。
- 文献检索先尝试学术接口，网络/API 限流后使用会议原文、论文全文和作者仓库交叉核对。没有把第三方榜单汇总当作本实验结果。
