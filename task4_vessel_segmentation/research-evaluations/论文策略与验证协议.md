# 任务4：论文策略、瓶颈证据与V3验证协议

日期：2026-11-03。目标是争取显著超过已有方案，而不是继续靠阈值、TTA和续训挤出千分位变化。当前已知线上分数仅为用户反馈的V1 **0.85042**；V2五折选模验证Dice为0.838632，尚无其线上结果。

## 先看实际瓶颈

审计源：`research-evaluations/bottleneck_audit.json`，只读取20张训练图的折外预测及其标签，没有使用测试标签。

| 观察 | 实测值 | 对策略的含义 |
|---|---:|---|
| 最近邻标签血管像素比例 | 8.633% | 保留原始血管核心的参考目标 |
| 官方转换脚本复现目标的血管比例 | 12.867% | 双线性缩放后任意非零视为前景，使血管面积增加49.05% |
| 漏检像素中位于转换新增边界的比例 | 66.54% | 宽度和边界建模是重要瓶颈，不能只优化连通性 |
| 误检像素中距目标边界不超过2px的比例 | 80.88% | 大量错误是边缘位置误差，不是大块背景误分 |
| 细血管中心线召回（局部半径≤1.5px） | 80.63% | 细结构还有明显遗漏 |
| 中等血管中心线召回 | 98.50% | 不能用较好的主血管表现掩盖细血管问题 |

这里的“新增边界”是相对最近邻缩放标签而言。比赛服务器的标签构造实现并未公开给本工程；不能将脚本造成的扩张直接称作医学标注错误，也不能保证它与服务器真值完全一致。训练和验证继续沿用此前与用户确认的标签/脚本约定，同时保留原始核心监督，避免只学习一个扩大后的轮廓。

审计中的标签辅助修正分数只是误差上限诊断，既不是可实现的测试分数，也不是提交候选。

## 论文筛选与取舍

| 论文及正式发表信息 | 核心设计 | 本项目判断 |
|---|---|---|
| [Dynamic Snake Convolution，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Qi_Dynamic_Snake_Convolution_Based_on_Topological_Geometric_Constraints_for_Tubular_ICCV_2023_paper.html) | 形变受约束的细长卷积核、多视图特征融合、拓扑连续性约束 | 值得作为备选结构；论文对照支持特征提取本身的重要性，但复杂采样和拓扑损失应分别验证 |
| [clDice，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html) | 在骨架与掩膜的交集中约束细管连通性 | 不作为第一主线：当前大量像素误差在宽度/边界，而clDice主要约束中心线与拓扑 |
| [GraphSeg，NeurIPS 2025主会](https://proceedings.neurips.cc/paper_files/paper/2025/hash/a3a931c0781a4608a2e5e6a12fb1eaa8-Abstract-Conference.html) | 结构/外观分解，统计视网膜图谱与可变形图先验 | 暂缓：核心目标是跨域泛化，包含图谱与变分推断链路；不宜在当前同来源20张图上直接完整堆叠 |

| [SAUNA，WACV 2025](https://openaccess.thecvf.com/content/WACV2025/papers/Dang_Image-Level_Regression_for_Uncertainty-Aware_Retinal_Image_Segmentation_WACV_2025_paper.pdf) | 根据边界距离和血管厚度构造软标签，配合图像级与像素级回归 | 支持区分血管结构和边界不确定性的思路；本轮不把其FIVES外部训练结果当作本比赛收益，也不直接替换提交目标 |

以上明确区分ICCV/CVPR/NeurIPS主会、WACV和专业期刊，不将所有论文都称作CCF-A。各文献的数据、掩膜、分辨率、FOV和训练协议不同，论文中的Dice数值不可直接与当前0.85042线上分数比较。

## V3的一个核心判断

**持续保留细血管的高分辨率特征，并分开监督原始血管核心与提交边界，应比继续训练同一个扩大轮廓预测器更有机会解决当前失分。**

这是待验证假设，不是已证实的结论，也不保证固定的线上涨幅。

### 实现范围

1. 采用官方FR-UNet结构；代码来源、Git blob SHA及MIT许可证保存在 `third_party/fr_unet`。
2. 使用论文实现的默认宽度（首层32通道，约738万参数），输入沿用RGB＋局部绿色对比度四通道。
3. 输出两个通道。第0通道预测原来的提交目标；第1通道仅用于辅助学习最近邻缩放的原始血管核心。
4. `plain`对照组只用第0通道损失。`core`组在完全相同架构上加入0.3倍核心BCE＋Dice辅助损失。两组结构、初始化、裁块、增强和数据顺序一致。
5. 最终提交始终由第0通道产生，不把辅助核心掩膜误当成官方提交目标。

这里复用了FR-UNet架构，并做了任务特定的双头适配；不声称完整复现FR-UNet论文训练协议，也不声称实现了SAUNA原论文的完整变换与损失。没有下载任何上游预训练血管权重，也没有引入外部眼底图或标签。

## 实验顺序与通过条件

1. 优先在较难的折2测试风险：`plain`和`core`分别训练至1,200步，预设总计划为2,600步，学习率调度不因初测停止点改变。
2. 比较辅助监督是否有独立收益，同时看相对旧模型的主掩膜Dice、细血管召回和边界错误。只提高辅助任务分数不算成功。
3. 若1,200步仍在明显学习，可按原计划从最新优化器状态继续，而不是把尚未收敛当作失败。恢复时保存模型、优化器、AMP、CPU/CUDA RNG和裁块生成器状态。
4. 在另一个折（折0）重复较好的方案，避免只优化最差一折。旧版的折2/折0及五折划分保持固定。
5. 候选方案至少应在两折平均主Dice上比当前V2高约0.008，且不能用一折大涨掩盖另一折明显退化，才值得扩展五折。若仅千分位收益或学习曲线已平，终止该路线并回到结构备选，不能把它包装成显著突破。
6. 通过后完成五折，按OOF选择阈值和必要的模型组合，生成新CSV并用官方脚本和独立RLE回读校验。最终仍需线上提交验证，不能把验证涨幅直接加到0.85042上。

当前初测命令：

```powershell
python -u -X utf8 v3.py train --folds 2 --arms plain core --steps 2600 --stop-at 1200
```

日志：`v3/pilot.log`；最新进度：`v3/status.json`。继续完整计划时使用 `--resume --stop-at 2600`。旧版V1/V2代码、权重和提交文件保留。

## 追加的协议分离验证（在扩跑前决定）

边界扩张是已知确定性算子，因此另设原生分辨率路线：在原始584×565图像及未缩放血管标签上学习，先将原生预测二值化，再由官方双线性512＋非零判定生成最终掩膜。这样让模型学习图像中的血管，转换算子负责提交所需的扩张。

`operator_probe.json` 表明，仅把V2的512预测提高阈值后反转换没有收益，不能作为免费后处理宣称提升。用最近邻标签重构原生网格再转换的0.96666只说明该算子链路的信息上限，使用了验证真值，不是模型成绩。

原生路线须先通过以下检查再训练：原生GT经过实现的转换算子，与当前官方脚本复现验证目标逐像素完全一致；预测须先补齐8的倍数、再裁回584×565后转换，不能转置或把补边像素写入提交。实现见 `v3_native.py`，只改变学习目标/输入网格及验证转换，使用同一FR-UNet和相同折划分。从原生标签训练的效果必须实测，不能用上述真值重构分数替代。

## 初测结果与最终扩跑决策

折2同为1,200步：FR-UNet直接扩大目标0.80580、核心辅助0.80839、原生网格0.81408，均未明显超过V2的该折约0.8138。因此没有把这三条路线直接扩为五折，也没有将单个辅助任务提高称作成功。

进一步采用通用ImageNet ResNet-18初始化编码器，并保留独立的全分辨率32通道细节分支，构成任务特定TransferUNet。此设计结合原生网格监督与官方转换算子分离；不是对某篇论文的完整复现。ImageNet权重来自已缓存的torchvision官方文件，完整SHA-256验证为 `f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`，记录在 `pretrained/resnet18_provenance.json`。没有使用公开DRIVE训练/测试血管权重，也没有加入外部眼底标签。该初始化包含通用ImageNet数据先验，不能再称作完全从零训练。

编码器学习率为解码器的0.1倍，冻结编码器BN运行统计、保留其仿射参数可训练。解码器训练时BN正常更新。设置遵循小样本迁移学习的稳定性考虑，最终是否有效以当前折外分数判断。

完成2,000步后，原生阈值统一0.30的两折平均约0.84197。为与旧版512置信图组合，按预定义100个均匀阈值分别执行同一官方二值转换，再平均为512网格上的单调置信图。这是转换算子的离散积分，不是医学上校准的概率，也不是把灰度概率图直接交给“非零”编码器。

两折组合初测：新模型占0.75、旧模型占0.25、统一阈值0.35时，折0约0.86335、折2约0.82444，平均0.84389。相比V2相同两折约0.8353，提升约0.0086，超过预定0.008门槛，两折均无回退，因此继续训练折1、3、4。此时只证明扩跑值得做，不代表五折或Kaggle最终分数已经达到该值。

额外检查了整图推理与训练尺寸重叠裁块推理。官方FR-UNet本身也使用整图测试，所以不能将它视作实现错误。预训练候选折2实测整图0.81690、重叠裁块0.81680，后者没有收益，排除。

剩余三折命令：

```powershell
python -u -X utf8 v4_transfer.py --folds 1 3 4 --steps 2000 --stop-at 2000 --resume
```

日志：`v4/full_remaining.log`。五折齐全后重新按全部20张OOF预测统一选择组合权重和阈值，不能沿用只在两折上最优的配置冒充完整验证结果。

最终测试集成的算子次序也与OOF一致：每个模型先在原生网格预测、完成旋转平均，再各自映射到512提交置信图，最后跨模型平均。该转换非线性，不能默认“原生概率先跨模型平均再转换”等价。额外随机种子只作诊断，使用最终固定的全局组合比例和阈值，不重新选择参数，也不加入主测试集成。
