# 公开眼底模型：下载与验证

本轮用于寻找已学习眼底血管的完整分割权重。原V4使用的是通用ImageNet分类预训练，两者不同。原V4代码、权重和提交CSV保留。

## 主候选：RLAD-SwinV2-Large

- 作者模型页：https://huggingface.co/JonathanFhima/RLAD-SwinV2-Large
- 原论文：https://arxiv.org/abs/2503.01190
- 固定仓库版本：`cf1f116d6b9898aa7b2aa3b075e071d3460e3a6e`。
- 权重：`rlad_swinv2_large/model.safetensors`，806,056,424字节。
- 上游LFS SHA-256：`904c8c20ba38ff23f4350454349ce92e1cb7bbbcefe214243d3f458ecc8f3338`；下载脚本必须核对后才将分段文件合成为正式权重。
- 作者列出的分割训练来源为UZLF、GRAPE、MESSIDOR、ENRICH、MAGRABIA和PAPILA；论文将DRIVE作为域外评估集。没有对无法取得的上游完整训练集做逐图哈希查重，因此不能宣称已完成独立的全量数据审计。
- 代码为Apache 2.0，权重限定非商业研究用途，详见原始`rlad_swinv2_large/README.md`。请保留来源和作者引用。

保留作者的输入预处理：RGB缩放至1444×1444，ImageNet标准化，补边到1472×1472，bfloat16推理。输出前两个通道分别为动脉、静脉；验证程序取两者概率的最大值作为血管并集。其余输出通道不参与本任务。

为了避免额外下载通用初始化和写入系统盘缓存，独立下载了SwinV2骨干配置到`backbone_config/config.json`，模型构建时用这个本地配置；分割权重仍严格加载作者完整state_dict。没有下载第二份ImageNet骨干权重。默认HF缓存也指向本项目。

从项目的task4目录运行：

```powershell
python -u -X utf8 evaluate_open_rlad.py
```

这只对所提供的20张训练图执行零样本推理和阈值/组合验证，不训练模型、不上传Kaggle、不改动V4提交。默认正确还原补边，结果记录在`open_models/rlad_evaluation_unpadded.log`及`open_models/rlad_evaluation_unpadded/metrics.json`。加`--geometry author`可复查最初未还原补边的流程。不能把论文中的动静脉指标当成本比赛的血管Dice。

### 坐标适配与本地实测

最初沿用上游最终缩放输出直接回原图，Dice为0.50425。图像审计发现固定补边没有还原：输入1472中间才是1444的有效图像，直接把整个输出压回原图会让细血管偏移。缓存上按已知比例逆变换可把验证Dice提高到约0.8404（原生阈值0.1），这只是诊断值。

最终适配直接读取原始1472×1472解码器输出，裁去四周各14像素，再映射回原始584×565图像；它避免先缩小到1444再逆变换造成的额外插值损失。裁边常数完全来自输入预处理尺寸，不由训练标签拟合。上游原始代码文件与完整权重均保留，没有改变网络权重，也没有微调。

重新完整推理20张训练图后：

| 方案 | 训练图上的选模验证Dice |
|---|---:|
| 原V4折外预测 | 0.845291675 |
| RLAD原生阈值0.5，经提交算子转换 | 0.811148735 |
| RLAD单独置信图，在0.2至0.8扫描范围内最佳 | 0.831142025 |
| RLAD与V4组合 | 0.850492373 |

最终组合为`0.5 * RLAD_confidence + 0.5 * V4_confidence`，阈值0.275；相对V4增加约0.00520 Dice，即0.520个百分点。RLAD的单模型数值不代表它优于V4；组合收益来自本地实测。RLAD未在本项目训练图上微调，但这20张图的标签用于选择阈值与组合比例，因此最终数值仍是选模验证估计，不是完全独立测试成绩。

当前环境bfloat16推理峰值显存约1.53 GB，每张模型推理约0.7秒，另有加载、预处理、提交网格映射与文件写出时间。

### 公开模型融合提交

```powershell
python -u -X utf8 predict_open_rlad.py
```

这会使用已确定的比例与阈值预测20张测试图，保存`open_models/delivery/submission_open_rlad.csv`，以官方脚本生成RLE并独立回读校验。原V4提交不覆盖。缓存重导出可用`python -u -X utf8 predict_open_rlad.py --cached`。CSV校验及SHA-256记录在同目录`submission_validation.json`。

## 备用：RBV-SIN

- 官方代码：https://github.com/CGGMFF/rbv-sin
- 论文：https://doi.org/10.1016/j.bspc.2024.107343
- 官方权重发布：https://github.com/CGGMFF/rbv-sin/releases/tag/v1.1.0
- 权重压缩包：`rbv_sin/trained_weights_h5.zip`，87,678,809字节。
- 官方README明确使用FIVES训练；模型代码MIT，图像和权重CC BY 4.0。许可证和上游README单独保留。
- 这是TensorFlow/Keras的H5权重。现有工程是PyTorch环境，本轮不将它误当作可直接加载的PyTorch模型，也不改写系统环境安装TensorFlow。

## 排除记录：R2-V2

官方仓库：https://github.com/j-morano/R2-V2

其技术报告称使用RITE等数据，并最终用全部组合数据训练。RITE官方说明它继承DRIVE全部40张图及对应训练/测试划分，见 https://eye.medicine.uiowa.edu/rite-dataset 。因此该权重存在本比赛数据重叠风险，不参与当前验证或提交。已获取的代码、配置和报告仅保留作来源审计，不将其高分当成无泄漏提升。

## 提交语义

保持当前已验证的实际标签与官方转换脚本约定：白色血管为RLE前景。验证程序先从原生预测映射到512×512提交网格，再与V4比较。比赛网页文字与实际材料的差异不通过更换公开模型自行反转。

所有本地验证分数都不是Kaggle新成绩；本轮没有自动提交。
