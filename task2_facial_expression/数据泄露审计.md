# 数据泄露审计（2026-10-18）

结论：目前不能证明 Dima 表情预训练权重无数据泄露，不能将本地 81.98%（原始权重）或 82.35%（线性适配）作为独立、无污染的泛化成绩。审计时曾停止后续模型队列；用户了解风险后已明确授权继续 Dima 主干微调。未提交 Kaggle，权重及已有实验保留。

## 预训练来源

- 权重：dima806/facial_emotions_image_detection，revision `747cf16692eea925b54b7b543cf436848128b68d`。
- 发布者模型卡和作者在讨论区的回答均指向 [Kaggle Notebook](https://www.kaggle.com/code/dima806/facial-emotions-image-detection-vit)。
- 本次通过 Kaggle 公开 API 获取了该 Notebook 的当前第 8 版源码。元数据引用 `samaneheslamifar/facial-emotion-expressions` 数据集。
- 源码 cell 4 使用 `glob('*/*/*.*')` 汇集目录下图片；cell 6 对图片路径进行 `RandomOverSampler.fit_resample`；cell 11 才执行 `train_test_split(test_size=0.4)`，没有按原始图片分组。复制后的同一图片可能进入两边。这是明确的评估设计缺陷，不能用其评估数字证明独立泛化。
- 当前 Notebook 与下载权重的训练版本是否完全一致，尚未获得证据；没有取得该权重实际训练图片清单。因此，不能断言该权重具体见过本比赛哪些图片，也不能保证没有见过。
- 继续微调、换分类头或重新划分本地验证集，都不能消除已经存在于预训练权重中的潜在污染。

## 处理建议

若要求避免表情任务预训练造成的潜在污染，应弃用无法核验训练样本的表情专用权重，改用来源明确的通用初始化，仅用本题训练子集训练；严格限定到完全已知训练来源时，可从随机初始化训练。通用预训练也不能在缺少逐图核对时获得绝对无重叠保证。保留单种子、按重复图片分组的验证，不承诺替换后仍达到 80%。

审计后用户已明确接受上述风险并授权继续使用 Dima 训练。后续恢复训练；本审计结论不变，不将其成绩作为无泄露成绩发布。
